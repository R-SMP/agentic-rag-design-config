**vacuum_hose_adapter** — build ``vacuum_hose_adapter.obj`` into an attempt
   folder with OpenSCAD from that attempt's own ``parameters.json`` (pass
   ONLY that file's path — the tool reads the values and writes beside
   them) AND, as its final step, render the three views (isometric / top /
   side).  Returns the model path, anything OpenSCAD said and the
   render+check report.
