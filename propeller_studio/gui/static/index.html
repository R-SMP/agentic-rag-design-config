fill draws the views and sections as large as their panels allow and states the true ratio (e.g. 1 : 1.24). standard rounds down to a preferred-series scale (2:1, 1:1, 1:2 …) — tidier numbers, but the series has nothing between 1:1 and 1:2, so on A3 with three views it costs about 40 % of the image size. Either way the title block states the scale actually used.

stacked: views across the top, sections in a band below. sections_right: views fill the left, sections run down a column on the right (a wider, more horizontal drawing); sections_left mirrors it. The column width applies to the two column layouts only.
