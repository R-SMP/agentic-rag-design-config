Each run: set its LLM condition, send the query, auto-send the continue-message while the reply is intermediate (up to the cap), snapshot the log to R2, then reset. Model context windows

              

                How large a context window each model has, in input tokens.
                The Context Pruner uses this to decide when an agent's history
                has grown too long: it prunes at
                max(min-threshold, min(fraction × window,
                max-threshold)), counting the system prompt as well as
                the history.
                Rows are matched as name prefixes, longest first,
                so claude-opus-4-5 (200k) wins over
                claude-opus for that model — which matters, because
                the window varies by version within a family.  Keep the short
                family rows conservative.
                Anthropic models are refreshed live from the provider API at
                session start and override this table; OpenAI exposes no window,
                so those rows are maintained here.  Changes take effect for the
                next session.

Clear previous-sessions folder

            

              Type the phrase clear_previous_sessions in
              the box below and press Enter or click
              Send to permanently delete every
              subdirectory inside the Railway volume's
              previous_sessions/ folder.  This removes
              the on-disk cache of past-session artefacts that
              retrieve_attempt /
              retrieve_user_inputs fall back to when the
              canonical store is unreachable.
            

            

              What gets wiped:
            

            
    
              
  • Every ID<NNN>_YYYYMMDD_HHMMSS/
                  directory directly inside
                  previous_sessions/ on the currently-
                  running container's volume
    • 
              
  • All per-attempt artefacts inside those directories
                  (renders, meshes, description.txt,
                  per-agent histories)
    • 
            

            

              What is preserved:
            

            
    
              
  • The Postgres database
                  (sessions, chunks,
                  dc_attempts, …) — use the red
                  Reset the database box for that
    • 
              
  • The R2 bucket — past-session artefacts archived to
                  R2 are untouched
    • 
              
  • The previous_sessions/ folder itself
                  (only its children are removed)
    • 
              
  • The current in-flight session (if any) — only
                  sessions already archived to
                  previous_sessions/ are affected
    • 
            

            

              This action is irreversible on the
              container's local volume.  If you need any of these
              files, re-download them from R2 first (canonical
              archive) before running this.  Scope is the current
              Railway container only — other deploys / local
              checkouts are untouched.

Database options

            

              Choose which database the workflow uses.  The choice is
              recorded for a future phase — for now every saved session
              is written to both the text-only and the
              multimodal database.
            

          


          


          
          


            
            

              
Text-only default

              

                The original text-embedding database.  Q+A entries are
                stitched and embedded with the configured text model.
                No images are embedded.
              

              

            


            
            

              
Single-vector multimodal

              

                Re-embeds every text entry and embeds the session's images
                (user images + attempt renders) fused image+text.
                Parameters are fixed this phase (read-only).
              

              


              
Image row mapping

              


              
Backfill past sessions

              

                Embed every past session into the multimodal table.
                Sessions already embedded at the current model are skipped
                unless you force a re-embed.  Progress streams below; the
                run continues server-side even if you leave this view.
