Database — developer console

This view exposes destructive database operations. Enter the password configured on the server (PASSWORD_DATABASE_WEB_UI) to unlock it. The password is held in browser memory only — refresh the page and you'll need to re-enter it.

Reset the database to a clean state

Type the phrase reset_database in the box below and press Enter or click Send to permanently delete:

  • All rows in sessions (cascades to chunks, dc_attempts, dc_attempt_parameters)
  • All rows in rag_queries

Preserved:

  • dc_parameter_schemas (the 17-parameter schema seed)
  • The session_counter SEQUENCE — the next session ID continues from the current count, not reset to 1. Manually reset via psql (ALTER SEQUENCE session_counter RESTART WITH 1;) if you want IDNNN to restart.

This action is irreversible. Make sure you are pointed at the right database.

End this session?

Choose whether to save this session for the database before archiving it. Saving runs the Database Handler over every agent's history — this can take several minutes; the LOG and Status chart lights up the Database Handler box while it runs.

"Cancel" closes this dialog and leaves the session running.
